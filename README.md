# Recursos Gratuitos de Inteligencia Artificial para Creadores y Estudiantes

¡Bienvenido! Este es un proyecto de código abierto bajo licencia MIT que recopila las mejores herramientas, cursos y recursos gratuitos sobre Inteligencia Artificial para que cualquier persona pueda aprender y crear sin barreras económicas.

## 🚀 Modelos y Chats Gratuitos
* [Claude](https://claude.ai) - Ideal para redacción, análisis de datos y explicaciones complejas.
* [ChatGPT](https://chatgpt.com) - Excelente para lluvia de ideas y asistencia general.

## 🎨 Generación de Imágenes y Arte
* [Tensor.art](https://tensor.art) - Generación gratuita de imágenes con modelos avanzados.
* [SeaArt AI](https://seaart.ai) - Herramienta robusta para crear arte digital mediante prompts.

## 📚 Cursos y Aprendizaje Gratis
* [Elementos de IA](https://elementsofai.es) - Curso básico gratuito ideal para principiantes.
* [Google Cloud Skills Boost](https://google.com) - Introducción a la IA generativa impartido por Google.

## 🤝 Cómo contribuir
Este proyecto es comunitario. Si conoces alguna herramienta gratuita que deba estar aquí, ¡haz un Pull Request o abre un Issue para añadirla!
